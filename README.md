# LimePhoenix

Closest Autonomous Courier Wins.

Documents & small parcels ≤10 lb via Cybercab (Austin) and Waymo (Los Angeles). Chooses whichever is closest.

Plus Phoenix Desktop Companion: Clippy from Windows 98/XP reborn in 2026 with RSI HSI Learning, watching clicks & browser movements, recursive memory layers (Episodic → Semantic → Procedural), local-first LLM + personalization.

**By Matryxx LLC, Sheridan, Wyoming.**

Style: easy to read, minimalist, clean lines, emboss features, lime green to stand out.

## Features
- Courier Matching: ETA-first, predictive graph neural rebalancing, closest vehicle wins.
- gnomies Item-Drop Desk with bells + carousel.
- Phoenix Assistant: spirit/soul, mouth, phoenix/bird-of-paradise, mecha-brain accents, dookie emoji allowed.
- Coexist.llc totem pole (gold / obsidian / glass transparency).
- Hologram Prism, Tesla Blueprint Scroll, Waymo Tech Synthesis, carTPU (5nm ASIC >1,000 TOPS).
- 25SHA Web3 wallet ID artifact (token recycle mock).
- Production path open via Open Hands CLI + Vercel CLI. Human gate remains on domain, deploy, email, privacy scope.

## Deploy to Vercel
```bash
cd limephoenix
npm install
npm run build
# or vercel --prod
```

Or push to GitHub and import to Vercel.

## Local Dev
```bash
npm run dev
```

Open http://localhost:3000
